# 03. 客户端门户 UI/UE 设计

## 1. 定位与边界

客户端门户服务外部客户，包括货主、卖家、客户主账号、子账号、财务、跟单员和技术对接人员。它不是内部后台的简化版，而是客户自助完成下单、查库存、看账单、处理异常和管理 API 的门户。

客户端必须与管理端隔离：

| 项 | 客户端 |
| --- | --- |
| URL | `/client/login` |
| 登录身份 | 外部客户账号 |
| 数据范围 | 当前客户企业及其授权范围 |
| 权限模型 | 主账号/子账号/客户角色 |
| 语言 | 面向客户，避免内部术语 |
| 风险 | 公网暴露，必须考虑限流、密码策略、MFA 预留 |

## 2. 信息架构

| 一级菜单 | 页面 | 目标 |
| --- | --- | --- |
| 工作台 | 概览、待办、异常提醒 | 告诉客户今天需要处理什么 |
| 订单履约 | 出库订单、入库预报、退货申请 | 自助创建、追踪、处理异常 |
| 商品库存 | SKU、库存看板、尺重复测记录 | 管理商品和库存状态 |
| 账单财务 | 账单、扣费流水、充值、发票 | 看清费用和余额风险 |
| 开发者中心 | API 凭证、白名单、调用日志、映射 | 支持 ERP/WMS/TMS 对接 |
| 账号权限 | 子账号、角色、登录日志 | 客户企业内部权限管理 |
| 客服支持 | 工单、公告、帮助文档 | 处理问题和获取支持 |

## 3. 客户端登录

页面目标：让客户明确自己进入的是“客户门户”，不是内部管理端。

登录内容：

- 企业编码或客户编码。
- 登录账号。
- 密码。
- 验证码。
- 首次登录强制改密。

视觉方向：

- 使用更清晰的业务语言：订单、库存、账单、API。
- 不展示内部菜单、租户、部门、角色等内部概念。
- 失败提示要区分：企业不存在、账号禁用、密码错误、验证码错误、账号锁定。

## 4. 客户工作台

工作台首屏需要回答四个问题：

1. 今天有多少订单需要处理？
2. 哪些异常会阻断发货？
3. 库存是否存在缺货风险？
4. 账单余额是否影响履约？

布局：

```text
KPI strip: 待处理订单 / 库存预警 / 待确认账单 / 异常工单
Main list: 待办事项
Side panel: 余额风险 / 公告 / 最近同步
Charts: 发货趋势 / 热销 SKU / 库存周转
```

交互：

- 每个待办必须可点击进入处理页。
- 异常卡片必须说明原因和下一步。
- 财务风险必须突出余额、信用额度、欠费状态。

## 5. 订单与履约

### 5.1 出库订单列表

查询条件：

- 订单号、平台单号、收件人、SKU、状态、仓库、创建时间。

表格列：

- 订单号、收件人、目的地、SKU 数、物流产品、状态、异常原因、创建时间、操作。

操作：

- 查看详情、取消、修改地址、重新推送、下载面单、查看轨迹。

状态解释：

- 待审核、待锁库、缺货挂起、欠费挂起、待打单、已下发 WMS、已出库、已取消。

### 5.2 入库预报列表

查询条件：

- ASN 单号、仓库、运输方式、状态、创建时间。

核心操作：

- 新建预报、导入模板、下载箱标、查看到货差异、确认差异。

### 5.3 异常处理

异常必须独立可追踪：

- 地址校验失败。
- 库存不足。
- 欠费/余额不足。
- 面单获取失败。
- WMS 拒单。
- 商品未同步。

每个异常展示：

- 原因。
- 影响。
- 可执行动作。
- 联系客服入口。

## 6. 商品与库存

### 6.1 SKU 列表

字段：

- SKU Code、Seller SKU、商品名称、分类、申报价值、HS Code、尺重、敏感属性、状态。

操作：

- 新建、导入、编辑、同步至 WMS、查看复测记录、冻结。

状态：

- 草稿、可用、已实测、冻结。

### 6.2 库存看板

库存维度：

- 在途库存。
- 在库可用。
- 待出库。
- 冻结/锁定。
- 坏品/瑕疵。
- 已出库。

页面规则：

- 默认按 SKU 聚合，可切换按仓库、批次、客户账号。
- 库存变动需要支持查看流水。
- 可用库存应解释计算口径。

## 7. 账单与财务

账单中心必须让客户看清“为什么扣费、扣了多少、是否影响发货”。

页面：

- 账单汇总。
- 扣费流水。
- 充值记录。
- 发票申请。
- 对账争议。

字段：

- 费用类型、关联单号、发生时间、币种、金额、余额、计费规则快照。

## 8. 开发者中心

页面目标：让客户技术人员自助完成 API 对接。

能力：

- AppKey / AppSecret 生成、重置、禁用。
- IP 白名单。
- Webhook 地址配置。
- API 调用日志。
- ERP 渠道映射、仓库映射、SKU 映射查看。

安全规则：

- Secret 仅创建时完整展示。
- 重置 Secret 需二次确认。
- 调用失败日志需显示错误码、请求路径、时间和追踪 ID。

## 9. 客户账号与权限

客户账号采用主子账号体系：

| 角色 | 权限 |
| --- | --- |
| 主账号 Admin | 管理企业全部订单、账单、SKU、API、子账号 |
| 操作员 | 创建和管理订单、入库、退货 |
| 财务 | 查看账单、充值、发票、费用流水 |
| 技术 | 管理 API 凭证、白名单、调用日志 |
| 只读成员 | 查看授权范围内数据 |

子账号数据范围：

- 仅自己创建。
- 当前部门/团队。
- 整个客户企业。
- 指定仓库或业务线。

## 10. 客服与异常

工单中心字段：

- 工单号、类型、关联单据、状态、优先级、最近回复、创建时间。

状态：

- 待处理、处理中、待客户回复、已解决、已关闭。

规则：

- 客户从异常页发起工单时，自动带入关联单号和错误上下文。
- 客服回复后在工作台产生待办。

## 11. 原型优先级

1. 客户端登录、主框架、工作台。
2. 出库订单列表、库存看板、账单中心。
3. SKU 列表、入库预报、开发者中心。
4. 子账号权限、工单中心。
5. 退货、VAS、对账争议。
