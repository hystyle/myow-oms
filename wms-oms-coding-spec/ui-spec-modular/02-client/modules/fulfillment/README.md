# 客户端模块：订单履约

订单履约用于客户自助创建、查询、追踪和处理出库订单、入库预报和退货申请。

## 页面清单

| 页面 | 路由 | 优先级 |
| --- | --- | --- |
| 出库订单 | /client/outbound | P0 |
| 创建出库单 | /client/outbound/create | P0 |
| 入库预报 | /client/inbound-asn | P0 |
| 退货申请 | /client/return | P2 |

## 实现要求

- 必须遵守 `../../../00-global/` 下的全局约束。
- 具体页面必须声明：页面目标、路由、权限码、查询条件、表格列、状态枚举、API 映射、空态/异常态、验收标准。
- 客户端采用统一浅色产品视觉，但保留客户侧友好文案、自助引导、数据隔离和权限控制。
