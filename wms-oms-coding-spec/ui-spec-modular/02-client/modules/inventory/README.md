# 客户端模块：商品库存

商品库存用于客户维护 SKU、查看库存看板、查询库存流水。

## 页面清单

| 页面 | 路由 | 优先级 |
| --- | --- | --- |
| SKU 管理 | /client/sku | P0 |
| 库存看板 | /client/inventory | P0 |
| 库存流水 | /client/inventory-flow | P1 |

## 实现要求

- 必须遵守 `../../../00-global/` 下的全局约束。
- 具体页面必须声明：页面目标、路由、权限码、查询条件、表格列、状态枚举、API 映射、空态/异常态、验收标准。
- 客户端采用统一浅色产品视觉，但保留客户侧友好文案、自助引导、数据隔离和权限控制。
