# 客户端模块：账单财务

账单财务让客户看清为什么扣费、扣了多少、是否影响发货。

## 页面清单

| 页面 | 路由 | 优先级 |
| --- | --- | --- |
| 账单中心 | /client/billing/bill | P0 |
| 扣费流水 | /client/billing/charge-flow | P0 |
| 充值记录 | /client/billing/recharge | P1 |
| 发票申请 | /client/billing/invoice | P2 |

## 实现要求

- 必须遵守 `../../../00-global/` 下的全局约束。
- 具体页面必须声明：页面目标、路由、权限码、查询条件、表格列、状态枚举、API 映射、空态/异常态、验收标准。
- 客户端采用统一浅色产品视觉，但保留客户侧友好文案、自助引导、数据隔离和权限控制。
