# 客户端模块：客服支持

客服支持用于客户提交、追踪、回复工单，并查看公告和帮助文档。

## 页面清单

| 页面 | 路由 | 优先级 |
| --- | --- | --- |
| 工单中心 | /client/support/ticket | P1 |
| 公告 | /client/support/notice | P1 |
| 帮助文档 | /client/support/help | P2 |

## 实现要求

- 必须遵守 `../../../00-global/` 下的全局约束。
- 具体页面必须声明：页面目标、路由、权限码、查询条件、表格列、状态枚举、API 映射、空态/异常态、验收标准。
- 客户端采用统一浅色产品视觉，但保留客户侧友好文案、自助引导、数据隔离和权限控制。
