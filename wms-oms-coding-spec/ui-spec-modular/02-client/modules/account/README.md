# 客户端模块：账号权限

账号权限用于客户企业管理子账号、角色、数据范围和登录日志。

## 页面清单

| 页面 | 路由 | 优先级 |
| --- | --- | --- |
| 子账号 | /client/account/member | P1 |
| 角色 | /client/account/role | P1 |
| 登录日志 | /client/account/login-log | P1 |

## 实现要求

- 必须遵守 `../../../00-global/` 下的全局约束。
- 具体页面必须声明：页面目标、路由、权限码、查询条件、表格列、状态枚举、API 映射、空态/异常态、验收标准。
- 客户端采用统一浅色产品视觉，但保留客户侧友好文案、自助引导、数据隔离和权限控制。
