# 02-client 客户端 UI/UE 规范

客户端服务外部客户，包括货主、卖家、客户主账号、子账号、财务、跟单员和技术对接人员。

## 读取顺序

1. 先读 `../00-global/`。
2. 再读 `00-client-overview.md`。
3. 根据菜单进入 `modules/<module>/`。
4. 读取模块 README 与具体页面 spec。

## 模块分包

| 模块包 | 对应菜单 | 说明 |
| --- | --- | --- |
| `dashboard` | 工作台 | 概览、待办、异常提醒 |
| `fulfillment` | 订单履约 | 出库订单、创建出库单、入库预报 |
| `inventory` | 商品库存 | SKU、库存看板、库存流水 |
| `billing` | 账单财务 | 账单、扣费流水、充值、发票 |
| `developer` | 开发者中心 | API 凭证、调用日志、白名单、映射 |
| `account` | 账号权限 | 子账号、角色、登录日志 |
| `support` | 客服支持 | 工单、公告、帮助文档 |
