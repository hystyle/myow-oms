# 01-admin 管理端 UI/UE 规范

管理端服务内部运营、销售、财务、风控、客服和系统管理员。

## 读取顺序

1. 先读 `../00-global/`。
2. 再读 `00-admin-overview.md`。
3. 根据菜单进入 `modules/<module>/`。
4. 读取模块 README 与具体页面 spec。

## 模块分包

| 模块包 | 对应菜单 | 说明 |
| --- | --- | --- |
| `dashboard` | 工作台 | 内部运营概览、待办、预警 |
| `user` | 用户中心 | 用户、角色、菜单、部门、数据权限、安全策略 |
| `system` | 系统中心 | 定时任务、通知公告、站点配置、日志、文件 |
| `customer` | 客商中心 | 客户、供应商、联系人、地址、黑名单 |
| `oms` | 海外仓 OMS | SKU、库存、入库、出库、异常、仓库、物流产品 |
| `firstmile` | 头程管理 | 头程订单、费用、轨迹、单证 |
| `finance` | 财务中心 | 报价合同、账单、扣费流水、对账 |
| `integration` | 集成中心 | API 凭证、同步日志、映射 |
