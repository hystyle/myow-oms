# 管理端模块：财务中心

财务中心覆盖报价合同、账单管理、扣费流水、对账记录，强调费用可信、规则可追溯。

## 页面清单

| 页面 | 路由 | 优先级 |
| --- | --- | --- |
| 报价合同 | /admin/finance/quote-contract | P0 |
| 账单管理 | /admin/finance/bill | P0 |
| 扣费流水 | /admin/finance/charge-flow | P0 |
| 对账记录 | /admin/finance/reconcile-record | P1 |

## 实现要求

- 必须遵守 `../../../00-global/` 下的全局约束。
- 具体页面必须声明：页面目标、路由、权限码、查询条件、表格列、状态枚举、API 映射、空态/异常态、验收标准。
- 管理端采用统一浅色产品视觉，但保留高密度查询、表格、批量操作、内部异常和审计追踪能力。
