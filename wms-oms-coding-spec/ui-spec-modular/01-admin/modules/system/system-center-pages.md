## 3. 系统中心 P0 页面

### 3.1 定时任务管理

页面目标：维护系统后台任务，支持暂停、恢复、立即执行和查看日志。

表格列：

- 任务名称、任务组、Cron 表达式、处理器、状态、最近执行时间、操作。

操作：

- 新增、编辑、暂停、恢复、执行一次、查看日志。
- 执行一次必须二次确认。
- Cron 输入应支持下次执行时间预览。

### 3.2 任务执行日志

页面目标：排查任务执行结果。

查询条件：

- 任务名称、任务组、执行状态、时间范围。

详情弹窗：

- 参数、开始时间、结束时间、耗时、异常堆栈。
- 异常堆栈默认折叠，支持复制。

### 3.3 通知公告

页面目标：发布内部通知和客户可见公告。

表格列：

- 标题、类型、发布范围、状态、发布时间、发布人、操作。

编辑抽屉：

- 基本信息：标题、类型、摘要、内容。
- 可见范围：内部角色、部门、客户范围。
- 发布设置：立即发布、定时发布、有效期。

状态流：

`草稿 -> 已发布 -> 已下线`

### 3.4 站点配置

页面目标：维护系统级配置项，支持分组、敏感配置脱敏和变更审计。

字段：

- 配置 Key、配置名称、配置值、分组、是否敏感、备注。

规则：

- 敏感配置默认脱敏展示，查看明文需要权限和审计。
- 修改配置后提示是否需要重启或立即生效。

### 3.5 文件管理

页面目标：管理上传文件、附件、导入模板和导出结果。

能力：

- 上传、下载、预览、删除。
- 展示文件类型、大小、业务归属、上传人、上传时间。
- 删除前说明业务引用影响。

### 3.6 操作日志 / 登录日志

操作日志用于审计业务动作，登录日志用于安全追踪。

操作日志列：

- 操作人、模块、动作、对象、结果、IP、时间。

登录日志列：

- 账号、登录结果、IP、设备、地点、时间、失败原因。

规则：

- 日志不可编辑。
- 失败原因必须可读。
- 敏感参数脱敏。


## 4. 空态与异常态

| 场景 | 文案规则 |
| --- | --- |
| 无数据 | 说明当前筛选无结果，并提供重置筛选 |
| 无权限 | 说明缺少的业务权限，提示联系管理员 |
| 接口失败 | 展示失败原因和重试入口 |
| 保存失败 | 指出具体字段或业务校验原因 |
| 删除失败 | 说明关联数据或状态限制 |

## 5. 原型开发顺序

1. 登录页、主框架、403/404。
2. 用户管理、角色管理、菜单管理、部门管理。
3. 定时任务、任务日志、通知公告、站点配置。
4. 文件管理、操作日志、登录日志。
5. 客商中心和海外仓 OMS 页面。
