# 管理端模块：系统中心

系统中心负责定时任务、任务日志、通知公告、站点配置、文件、操作日志和登录日志。

## 页面清单

| 页面 | 路由 | 优先级 |
| --- | --- | --- |
| 定时任务 | /admin/system/job | P0 |
| 通知公告 | /admin/system/notice | P0 |
| 站点配置 | /admin/system/config | P0 |
| 操作日志 | /admin/system/operation-log | P1 |
| 登录日志 | /admin/system/login-log | P1 |

## 实现要求

- 必须遵守 `../../../00-global/` 下的全局约束。
- 具体页面必须声明：页面目标、路由、权限码、查询条件、表格列、状态枚举、API 映射、空态/异常态、验收标准。
- 管理端采用统一浅色产品视觉，但保留高密度查询、表格、批量操作、内部异常和审计追踪能力。
