# 04. 组件与交互规范

## 1. 查询区

查询区服务快速定位数据，不做复杂业务编辑。

规则：

- 一行优先展示 3-5 个条件。
- 常用条件默认显示，高级条件折叠。
- 操作顺序：查询、重置；导出不放在查询区，放工具栏。
- 输入后回车触发查询。
- 重置必须清空筛选并回到第一页。

## 2. 工具栏

工具栏放置对列表产生影响的操作：

- 主操作：新增、导入、创建预报。
- 批量操作：批量删除、批量启用、批量同步。
- 辅助操作：导出、刷新、列设置。

危险批量操作必须展示影响条数。

## 3. 侧边导航

侧边导航用于承载一级业务域和模块页面，不应把所有菜单长期全部展开。

规则：

- 侧边导航按一级业务域分组时，分组标题必须支持折叠/展开。
- 当前路由所在分组默认自动展开。
- 用户手动展开/收起状态在当前会话内保持。
- 菜单数量较多时，禁止把所有子菜单长期全部展开导致侧栏溢出。
- 分组折叠后必须保留分组标题和展开指示，不隐藏整个业务域。
- 权限过滤后为空的分组不展示。

## 4. 表格

表格是管理端最高频组件。

列规则：

- 第一列优先放名称、编码或单号。
- 状态列靠近操作列。
- 时间列统一格式 `yyyy-MM-dd HH:mm:ss`。
- 操作列固定右侧。
- 编码、单号支持复制。

交互规则：

- 加载中保持表头和布局稳定。
- 空态显示当前筛选无结果，并提供重置筛选。
- 行内操作超过 3 个时使用“更多”菜单。
- 删除、停用、冻结、重置密钥必须二次确认。

## 5. 表单

表单必须面向业务填写，而不是面向数据库字段。

字段规则：

- 必填字段显示明确标识。
- 枚举字段使用下拉、单选或分段控件。
- Boolean 字段使用开关或单选，不使用自由文本。
- 金额必须带币种。
- 尺重必须带单位。
- ID 字段作为字符串处理，不使用数字输入框。

校验规则：

- 前端校验解决格式问题。
- 后端校验解决业务规则。
- 校验错误应定位到字段。

## 6. 抽屉与弹窗

| 类型 | 使用场景 |
| --- | --- |
| 抽屉 | 新增/编辑复杂实体，包含多个分组 |
| 弹窗 | 轻量确认、简单字段编辑、详情预览 |
| 全页 | 多步骤配置、强上下文页面、复杂详情 |

抽屉规则：

- 底部固定操作区：取消、保存。
- 保存中按钮禁用，避免重复提交。
- 关闭未保存表单时提示确认。

弹窗规则：

- 标题必须说明动作。
- 危险动作正文必须说明影响。
- 主按钮文案与触发动作一致。

## 7. 状态与反馈

全局反馈：

- 成功：toast，短文本。
- 失败：toast 或错误条，说明原因。
- 长任务：进入任务日志或同步日志，不只显示“已提交”。
- 下载：开始下载后提示，失败需显示原因。

状态标签：

| 状态 | 视觉 |
| --- | --- |
| 启用/完成/成功 | 绿色标签 |
| 草稿/待处理/暂停 | 琥珀标签 |
| 禁用/失败/冻结 | 红色标签 |
| 同步中/处理中 | 青色标签 |
| 归档/关闭 | 灰色标签 |

## 8. 异常页

### 403

内容：

- 标题：无权访问。
- 说明：当前账号缺少访问该页面的权限。
- 动作：返回首页、联系管理员。

### 404

内容：

- 标题：页面不存在。
- 说明：链接可能已失效，或当前菜单未配置。
- 动作：返回首页。

### 500 / 接口异常

内容：

- 展示接口错误信息。
- 展示追踪 ID。
- 提供重试。

## 9. 响应式规则

管理端主要服务桌面端，但必须保证窄屏可用：

- 低于 1200px：侧边栏可折叠。
- 低于 900px：查询区改为单列或双列。
- 表格横向滚动，不压缩到文字重叠。
- 抽屉宽度不超过视口宽度。

客户端需适配移动端查看：

- 工作台卡片堆叠。
- 表格转为列表摘要或横向滚动。
- 核心操作按钮保持可触达。

## 10. 权限控制

权限控制必须在 UI 上体现：

- 无权限按钮默认不展示。
- 状态不允许的操作置灰，并通过 tooltip 说明原因。
- 字段脱敏后提供“申请查看”或“需要权限”说明。
- 客户端不得展示内部权限码。

## 11. OpenAPI 与页面生成

为了支持后续根据 API 文档生成 UI 页面，接口说明必须满足：

- 每个接口有 summary 和 description。
- DTO 字段有 description、example、required。
- 枚举字段说明所有取值。
- 分页响应结构统一。
- 错误码与业务错误文案可映射。
- 权限码与接口动作一致。

前端生成页面时默认映射：

| DTO 信息 | UI 映射 |
| --- | --- |
| `string` + `format: date-time` | 日期时间 |
| `boolean` | 开关/是否标签 |
| enum | 下拉/单选 |
| required | 必填 |
| description | label / tooltip |
| example | placeholder |
