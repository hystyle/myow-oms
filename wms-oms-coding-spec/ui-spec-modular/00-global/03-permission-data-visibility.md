# 03. 权限、数据可见性与字段脱敏规范

## 1. 目标

MYOW 同时包含内部管理端和外部客户端。权限设计不能只控制菜单，还必须控制按钮、数据范围、字段可见性和当前状态下能否操作。

## 2. 权限控制层级

| 层级 | 控制内容 | 示例 |
| --- | --- | --- |
| 菜单权限 | 是否能看到菜单和进入路由 | 是否展示“出库订单管理”菜单 |
| 页面权限 | 是否能访问页面 | 直接访问无权限路由返回 403 |
| 按钮权限 | 是否展示页面动作 | 新增、导出、重新下发、审核 |
| 数据权限 | 能看到哪些记录 | 只看所属销售客户、所属部门客户 |
| 字段权限 | 敏感字段是否展示 | 手机、邮箱、成本价、API Secret |
| 操作条件 | 当前状态是否允许动作 | 已出库订单不可取消，失败状态才可重试 |

## 3. 权限码命名规则

格式：

```text
<domain>:<resource>:<action>
```

常用 domain：

| domain | 含义 |
| --- | --- |
| `system` | 用户中心、系统中心 |
| `customer` | 客商中心 |
| `oms` | 海外仓 OMS |
| `firstmile` | 头程管理 |
| `finance` | 财务中心 |
| `integration` | 集成中心 |
| `client` | 客户端门户 |

常用 action：

| action | 含义 |
| --- | --- |
| `query` | 查询列表 |
| `detail` | 查看详情 |
| `add` | 新增 |
| `update` | 编辑 |
| `delete` | 删除 |
| `import` | 导入 |
| `export` | 导出 |
| `enable` | 启用 |
| `disable` | 禁用 |
| `audit` | 审核 |
| `cancel` | 取消 |
| `resend` | 重新推送 / 重新下发 |
| `retry` | 重试 |
| `download` | 下载 |
| `reset` | 重置 |
| `view-secret` | 查看密钥 |
| `reset-secret` | 重置密钥 |

示例：

```text
oms:outbound:query
oms:outbound:detail
oms:outbound:resend
finance:bill:export
integration:api-credential:reset-secret
```

## 4. 管理端数据权限

管理端数据权限用于内部员工，不得与客户端客户数据范围混用。

| 数据范围 | 说明 |
| --- | --- |
| 本人 | 仅本人负责的数据 |
| 本人及下属 | 本人及组织树下级负责的数据 |
| 本部门 | 当前部门数据 |
| 本部门及下级 | 当前部门及下级部门数据 |
| 指定部门 | 角色绑定指定部门 |
| 全部 | 平台级运营和管理员 |
| 指定客户 | 针对销售、客服、运营绑定的客户范围 |

## 5. 客户端数据范围

客户端只允许查看当前客户企业及其授权范围内的数据。

| 范围 | 说明 |
| --- | --- |
| 仅自己创建 | 当前子账号创建的订单、ASN、工单 |
| 当前团队 | 当前客户组织下某团队的数据 |
| 整个企业 | 当前客户企业全部数据 |
| 指定仓库 | 仅指定仓库的订单和库存 |
| 指定业务线 | 如平台店铺、渠道、项目组 |

客户端不得出现内部部门、销售归属、内部客服归属等字段，除非该字段是客户明确可见的服务人员信息。

## 6. 字段脱敏规则

| 字段类型 | 管理端默认 | 客户端默认 | 说明 |
| --- | --- | --- | --- |
| 手机号 | 中间脱敏，可授权查看 | 当前客户联系人可见 | `138****5678` |
| 邮箱 | 局部脱敏，可授权查看 | 当前客户联系人可见 | `a***@domain.com` |
| API Secret | 仅创建时完整展示 | 仅创建时完整展示 | 后续只可重置，不可再次查看 |
| 成本价 | 需字段权限 | 不展示 | 客户端只看自己的计费结果 |
| 供应商报价 | 需字段权限 | 不展示 | 内部财务/运营使用 |
| 异常堆栈 | 需技术权限 | 不展示 | 客户端改为友好提示 |
| 内部备注 | 内部可见 | 不展示 | 客户端使用客户备注字段 |

## 7. 操作按钮展示规则

| 场景 | UI 规则 |
| --- | --- |
| 无权限 | 默认隐藏按钮 |
| 有权限但状态不允许 | 按钮置灰，并通过 tooltip 说明原因 |
| 危险操作 | 二次确认，说明影响范围 |
| 批量危险操作 | 确认框展示影响条数和不可恢复说明 |
| 长任务操作 | 提交后进入任务日志 / 同步日志，不只显示“已提交” |

## 8. 客户端异常文案映射

客户端不能直接展示内部异常、接口异常、任务失败、风险规则命中原因。必须转换为客户可理解的状态。

| 内部状态 / 异常 | 客户端展示 | 是否暴露内部原因 | 客户动作 |
| --- | --- | --- | --- |
| `WMS_API_TIMEOUT` | 仓库状态正在同步，系统会继续更新 | 否 | 无需操作 |
| `WMS_REJECTED` | 仓库暂未接收该订单，请联系客服确认 | 否 | 联系客服 |
| `LABEL_PURCHASE_FAILED` | 物流面单暂未生成成功 | 否 | 重试 / 联系客服 |
| `ADDRESS_VERIFY_FAILED` | 收件地址需要确认 | 是 | 修改地址 |
| `INSUFFICIENT_BALANCE` | 账户余额不足，订单暂无法继续履约 | 是 | 去充值 |
| `OUT_OF_STOCK` | 库存不足，订单暂无法发货 | 是 | 补货 / 取消 / 联系客服 |
| `SYNC_JOB_FAILED` | 系统正在处理最新状态 | 否 | 无需操作 |
| `RISK_RULE_HIT` | 订单需要进一步确认 | 否 | 联系客服 |

## 9. 每个页面必须声明的权限矩阵

页面规格中必须包含：

```md
| UI 元素 | 权限码 | 状态条件 | 无权限处理 | 状态不满足处理 |
| --- | --- | --- | --- | --- |
| 新增按钮 | oms:outbound:add | - | 隐藏 | - |
| 重新下发 | oms:outbound:resend | status = WMS_FAILED | 隐藏 | 置灰 + tooltip |
```
